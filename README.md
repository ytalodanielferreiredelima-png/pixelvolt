# PIXELVOLT — Loja Gamer

Projeto front-end (HTML5, CSS3, Bootstrap 5, JavaScript e jQuery) desenvolvido para a atividade
de Codificação Front-End: página inicial (home) e login de uma loja de eletrônicos gamer.

## Estrutura
- `index.html` — menu, banner (carrossel), selo de confiança, novidades (com filtro de categoria
  e carrinho interativo), galeria (com lightbox) e newsletter.
- `login.html` — login com validação e campo de senha com mostrar/ocultar, e cadastro com
  efeito jQuery (`slideToggle`).
- `css/estilo.css` — estilização, tema neon dark, responsivo (media queries).
- `js/script.js` — funcionalidades em JavaScript puro (scroll ao topo, login, cadastro, filtro
  de produtos, carrinho, modal de galeria, newsletter, animações de entrada).
- `js/jquery-script.js` — efeito de exibição do formulário de cadastro via jQuery.
- `img/` — ilustrações originais em SVG (logo, banners, produtos, galeria).
